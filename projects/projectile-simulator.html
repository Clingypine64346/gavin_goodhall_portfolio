Project context

Overview

The Projectile Launcher is an interactive MATLAB application that models the trajectory of a launched object based on user-defined launch speed, launch angle, and starting height. The simulator calculates key flight characteristics including maximum height, range, flight time, and impact velocity while displaying the trajectory graphically.

The Problem

I wanted to become more familiar with MATLAB by building a practical project from scratch. The goal was to create an interactive application where users could enter launch speed, angle, starting height, and gravity, then simulate and visualize the resulting projectile trajectory.

My Role

I independently designed and developed the Projectile Launcher in MATLAB. I created the projectile motion calculations, trajectory visualization, user inputs, and interactive interface while using the project to strengthen my MATLAB programming skills.

Design & Process

I began by building a basic MATLAB script using known projectile motion equations. Once the calculations were working correctly, I added a trajectory plot and gradually introduced additional outputs such as maximum height, range, flight time, and impact speed.

I then began developing a custom graphical interface so the simulation could be controlled interactively. After initially hardcoding the interface and its controls, I transitioned the project to MATLAB App Designer, which made the UI easier to build, organize, and expand. From there, I connected the user inputs to the calculations and visualization to create the final interactive application.

Challenges

One of the biggest challenges was learning MATLAB while developing the project. Since I was still becoming familiar with the language and its workflow, many parts of the project required experimentation and troubleshooting.

Another major challenge was building the user interface. I initially tried to hardcode the entire UI, which quickly became difficult to manage as more controls and features were added.

Solution / Iteration

I worked through the MATLAB learning curve by building the project incrementally, testing each calculation and feature before adding the next. This made it easier to identify errors and understand how different parts of the program worked together.

For the interface, I moved away from manually hardcoding every UI element and rebuilt it using MATLAB App Designer. This simplified the layout process and made it much easier to connect user inputs, calculations, and the trajectory visualization.

Final Result

The final result was a fully functional MATLAB application that allows users to enter launch speed, angle, starting height, and gravity to simulate projectile motion. The app calculates and displays the trajectory, maximum height, range, flight time, and impact speed in an interactive interface.

What I Learned

This project helped me become more comfortable with MATLAB and taught me how useful App Designer can be when developing interactive applications. I also gained experience translating engineering equations into working code and connecting calculations to user-controlled inputs and visualizations. Most importantly, the project reinforced the value of breaking a larger problem into smaller, manageable steps.
